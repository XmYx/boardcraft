# BoardCraft user research: what storyboard/animatic users complain about and ask for

## How to read the BoardCraft column

*Have / Avoided* = shipped; *(this pass)* = added in the polish pass of 2026-11-17; *Partly* = some
of it ships; *Planned* = ranked in [gaps.md](gaps.md); *Rejected* = out of scope, with the reason.

## Method and sources

- **Date of research:** 2026-11-17 (single desk-research pass, no interviews).
- **Reference apps:** Toon Boom Storyboard Pro (SBP), Storyboarder by Wonder Unit (SB), Boords, FrameForge,
  storyboarding in Photoshop / Procreate (incl. Procreate Dreams), StudioBinder storyboards.
- **Sources actually used:**
  - GitHub issues of `wonderunit/storyboarder`, queried through the GitHub search API (sorted by reactions and
    comments, plus title-keyword counts per theme). Keyword counts are *title hits*, not deduplicated complaints;
    treat them as an order-of-magnitude signal only.
  - Wonder Unit's own "Plan for Storyboarder v2" post (author-acknowledged v1 shortcomings and user asks).
  - Toon Boom community forum thread titles and search-result excerpts (forums.toonboom.com); the forum itself
    returned HTTP 403 to direct fetches, so only titles/snippets were read.
  - Boords public feature-request board (boords.canny.io, which the old community.boords.com now redirects to).
  - Adobe Community threads on Photoshop timeline/animatic workflows; r/ProCreate threads about Procreate Dreams
    (via a Reddit mirror that appeared in search results).
  - G2 / Capterra / TrustRadius listings for Boords and StudioBinder — **pages returned HTTP 403**, so only
    search-result snippets were seen.
  - DVinfo.net "Is FrameForge worth buying" thread (titles/snippets only).
- **Limitations:**
  - Reddit (r/storyboarding, r/animation, r/Filmmakers) could not be fetched and standard + one extended search
    surfaced almost no Reddit threads; Reddit voice is under-represented.
  - Review aggregators were blocked; their content is known only through short snippets. Small review counts
    (G2 Boords ~12–27 reviews, G2 StudioBinder ~15) make those signals weak.
  - FrameForge has very little public user feedback (SourceForge/Slashdot list no reviews); it is thinly covered.
  - Many "best storyboard software" pages are vendor- or affiliate-written (Boords, StudioBinder, Filmustage,
    Storyflow) and were used only as weak corroboration, never as the sole source for a user complaint.
  - Storyboarder GitHub is heavily over-represented because it is the only fully readable, high-volume source.
    Frequency labels below count *distinct sources/threads seen*, not users.
- **Rules followed:** everything paraphrased; no reviewer personal info; no invented counts. "Few (1–2)" where unsure.

Abbreviations: SBP = Storyboard Pro, SB = Storyboarder, PS = Photoshop, PC = Procreate / Procreate Dreams,
SBi = StudioBinder, FF = FrameForge.
